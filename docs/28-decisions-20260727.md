## 1. 六项决议

### 1.1 双轨处置 → **合流**

| 项 | 内容 |
|----|------|
| **决议** | 路径 B（本仓网关）通过 `path` / git 依赖复用路径 A 的 `image_schedule_core` + `image_schedule_trace`（二者已声明 `rlib`，无需 FFI） |
| **依据** | Panda 已在生产跑路径 A；本仓 `ticket_pool` 与 `pre_ticket_pool.py` 重叠 ~80%，重复造轮子 |
| **落地** | Phase C 接线时从 `../gptimage/crates/` 引入；**不在本仓重写** SlotLedger / DispatchGate / sediment / trace |
| **前置** | 路径 A 未入库源码（`dispatch_gate` / `lease_pool` / `sediment` / `image_schedule_trace`）须先进入 `gptimage` git（跨仓 P2，见 HANDOFF） |

### 1.2 `ticket_pool` → **冻结，移出 workspace**

| 项 | 内容 |
|----|------|
| **决议** | 保留 `crates/ticket_pool/` 源码备查，**不作为 workspace member 参与构建** |
| **依据** | Panda 票池由 `pre_ticket_pool.py` + 路径 A 调度栈承担；本 crate 零引用 |
| **落地** | `Cargo.toml` 已摘除 member；目录内 README 标注 frozen |

### 1.3 `control_client` → **移除 workspace**

| 项 | 内容 |
|----|------|
| **决议** | 保留源码备查，移出 workspace；Phase C **不对着** `/api/accounts/admission` 写（该端点在 Panda `:8012` **不存在**） |
| **依据** | [docs/24](24-gap-inventory.md) §3.3；Panda 调度面走 `humanlike_scheduler` + `slot_ledger` + 路径 A |
| **落地** | `Cargo.toml` 已摘除 member；Phase C 对接 Python 侧现有调度 HTTP（待盘点具体端点） |

### 1.4 鉴权模型 → **`:8012` API key 为 R2 目标；`:8013` 短期对齐现 Panda**

| 项 | 内容 |
|----|------|
| **决议** | ① **R2 切流 / 替换 `:8012`**：必须兼容生产 API key（`auth_service.authenticate(token)` 语义），`Authorization: Bearer` 不得改为仅 JWT；② **`:8013` 在切流前**：部署参数对齐现 Panda（`AUTH_DISABLE=1`、`IMAGE_ENABLED=1`、`GATEWAY_LISTEN=0.0.0.0:8013`），通过 env 覆盖 bringup 脚本新默认值；③ **JWT / Web UI**：作为 `:8013` **可选增强层**（dashboard 会话），不替代 OpenAI 兼容面的 API key |
| **依据** | `:8012` 全量客户端持 API key；`:8013` 现网无鉴权（[docs/25](25-panda-vs-rust-20260726.md) §3.1）；二者语义互斥是 R2 阻断项 |
| **落地** | 本提交不实现 API key 兼容（工作量项）；`docs/21` / bringup 文档注明 Panda 复现 env；R2 前单列「API key 透传或双验」任务 |

## 2. Panda 部署参数速查（复现现网 `:8013`）

```bash
AUTH_DISABLE=1 \
IMAGE_ENABLED=1 \
GATEWAY_LISTEN=0.0.0.0:8013 \
HELPER_INTERNAL_TOKEN=<from secrets/helper_token> \
bash scripts/panda_bringup_rust_face.sh
```

> bringup 脚本默认 `AUTH_DISABLE=0` / `IMAGE_ENABLED=0` / `127.0.0.1:8013`（安全缺省）。
> 上表 env **显式覆盖** 后方可 1:1 复现 2026-07-26 现采行为。
